MCP 2.0 PROTOCOL Universal Model Context Protocol

AI Agent API Harness & MCP Server

FlowGen exposes native Model Context Protocol (MCP) tools and high-throughput REST endpoints. AI agents in Claude Desktop, Cursor, Antigravity, and custom Python automation scripts can directly dispatch generation batches, query live progress, and retrieve output image paths.

Claude Desktop & Cursor Configuration

Add this entry to your claude_desktop_config.json:

{ "mcpServers": { "flowgen": { "command": "python", "args": ["browser2api/run_mcp.py"] } } }
Protocol: stdio JSON-RPC 2.0 • Zero external dependencies

Exposed MCP Tools

Callable natively by LLM agents

flow_generate POST / batch

Submit single or multi-prompt batch with model and ratio controls.

flow_get_status GET / state

Check engine readiness, online workers, and active generation state.

flow_get_history GET / analytics

Fetch historical project stats, image counts, and file locations.

Standardized tool contracts adhere to MCP 2024 specification

Direct REST API Harness

Programmatic execution via cURL or Python requests

curl -X POST http://127.0.0.1:8787/api/v1/generate \ -H "Content-Type: application/json" \ -d '{ "prompts": ["A futuristic supercar on neon wet asphalt", "Hyperrealistic crystal mountain peak at sunrise"], "project_name": "Cyberpunk Cars", "model": "nano_banana_2_1", "orientation": "portrait", "workers": 2, "wait_for_completion": true }'
